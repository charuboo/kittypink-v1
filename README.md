# 🌸 Pastel Pink Discord Theme
A cute pastel pink theme for Discord ♡

## Features

* Soft pastel pink colours
*  Cute Discord UI
*  Light and soft aesthetic
*  Easy to install and customise

## Installation
Download `theme.css` and import it into your preferred Discord CSS client/theme loader. I recommend **Vencord**!

## Customisation
The main colours and background can be changed at the top of `theme.css` to create your own variation.
